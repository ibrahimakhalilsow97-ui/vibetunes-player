# VibeTunes Player

"Créez une interface utilisateur complète pour une application musicale en utilisant uniquement HTML, CSS et JavaScript (pas de frameworks). L'application doit comporter les sections suivantes :

Un en-tête centré avec le nom de l'application (« VibeTunes ») et une barre de recherche.

Une section principale de lecteur de musique avec :
- L'image de la pochette de la chanson en cours
- Titre de la chanson et nom de l'artiste
- Les boutons "Play", "Pause" et "Next".
- Une barre de progression

une section horizontale défilante intitulée "Top Tracks", qui présente 5 pochettes d'album.

Utiliser une conception réactive et adaptée aux mobiles

Utilisez des dégradés doux, des coins arrondis et une esthétique moderne.

Utilisez un thème sombre et des boutons d'accentuation lumineux (tons bleus ou roses).

S'assurer que chaque élément de l'interface utilisateur a un identifiant unique afin de pouvoir y associer des fonctionnalités de la suite.

Pas de React ni de Vue - juste du code HTML, CSS et JS pour la mise en page.
